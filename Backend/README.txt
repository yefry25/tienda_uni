# Proyecto Tienda Uni

Este proyecto es una aplicación de backend para una tienda en línea utilizando Flask.

## Requisitos

- Python 3.x
- pip (gestor de paquetes de Python)

## Instalación

Sigue estos pasos para configurar y ejecutar el proyecto después de clonarlo:
  
1. Navega al directorio del proyecto
1. Crea un entorno virtual

python -m venv env

2. Activa el entorno virtual

source env/Scripts/activate

3. Instala las dependencias

pip install -r requirements.txt

4. Ejecuta la aplicación

python main.py
